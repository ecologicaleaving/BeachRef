### Data Models
Based on VIS Implementation Guide specifications:

**Tournament List Fields** (GetBeachTournamentList):
- `No`: string – tournament ID
- `Name`: string – tournament name  
- `CountryCode`: string – country identifier
- `City`: string – location city
- `StartDate`: string – YYYY-MM-DD format
- `EndDate`: string – YYYY-MM-DD format
- `Gender`: string – M/W classification
- `Level`: string – Challenge, Elite levels
- `Status`: enum – Scheduled/Running/Finished

**Round List Fields** (GetBeachRoundList):
- `No`: string – round ID
- `Name`: string – round name
- `Phase`: string – qualification, main draw phases
- `Order`: number – sequencing order

[Source: docs/architecture/VISImplementationGuide.md#2.1]
