# Story 004.1: MatchList Seed and Duration Display Enhancement

## Status
Done

## Story
As a **beach volleyball referee**, I want **to see team starting seeds/rankings and match duration displayed in the match cards**, so that **I can quickly assess team standings and match performance metrics for better tournament oversight**.

## Acceptance Criteria

1. **Seed/Ranking Display**
   - Team starting seed/ranking numbers are displayed in parentheses next to team names (e.g., "SMITH/JONES (#3)")
   - Rankings are only shown when available from VIS API data
   - No parentheses or ranking display when ranking data is unavailable
   - Ranking text uses subtle styling to maintain visual hierarchy
   - Ranking display works for both team names and individual player names

2. **Match Duration Display**
   - Total match duration is calculated from DurationSet1, DurationSet2, DurationSet3 fields
   - Duration is displayed in human-readable format (e.g., "1h 25m") in parentheses
   - Duration appears next to the set scores section
   - Duration is shown even for incomplete matches (partial duration from completed sets)
   - Duration calculation handles missing or invalid duration data gracefully

3. **Visual Integration**
   - Both features integrate seamlessly with existing MatchListV2 design
   - Text hierarchy maintained - rankings and duration use caption/secondary text styling
   - No layout disruption to existing match card structure
   - Features work consistently across all match card variants (current, upcoming, completed)

4. **Data Integrity**
   - Rankings use existing `Team{A|B}Ranking` data from VIS API via VisResponseParser
   - Duration uses existing `DurationSet1/2/3` fields from match data
   - No additional API calls required
   - Graceful handling of missing data fields
