# Story 1.2: Implement Batch Request Support

## Status
APPROVED

## Story
**As a** VIS API client system,  
**I want** XML batch request capability for multiple API calls in single request,  
**so that** I can reduce API calls by 30% and improve tournament detail page loading by 20% through efficient batching of related requests

## Acceptance Criteria

1. Create batch request XML builder supporting multiple Request elements
2. Update VisApiClient interface with executeBatchRequest method
3. Implement tournament detail batch (GetBeachTournament + GetBeachMatchList + GetBeachRoundList)
4. Add error handling for partial batch failures
5. Add integration tests for batch request scenarios

**Batch Request Interface** (to be added):
```typescript
export interface BatchRequest extends VisApiRequestBase {
  readonly requests: readonly BatchRequestItem[];
  readonly failureStrategy?: 'fail_all' | 'continue_on_partial';
}

export interface BatchRequestItem {
  readonly type: VisApiEndpoint;
  readonly request: VisApiRequestBase;
  readonly requestId?: string;
}

export interface BatchResponse extends VisApiResponse {
  readonly results: readonly BatchResponseItem[];
  readonly hasPartialFailures: boolean;
}

export interface BatchResponseItem {
  readonly requestId?: string;
  readonly type: VisApiEndpoint;
  readonly success: boolean;
  readonly data?: any;
  readonly error?: VisApiErrorResponse;
}
```

**Required XML Batch Request Format:**
```xml
<BatchRequest>
  <Request Type="GetBeachTournament" RequestId="req1" Fields="No,Name,City,Country">
    <Filter NoTournament="12345" />
  </Request>
  <Request Type="GetBeachMatchList" RequestId="req2" Fields="No,Status,Date,Time">
    <Filter NoTournament="12345" />
  </Request>
  <Request Type="GetBeachRoundList" RequestId="req3" Fields="No,Name,Phase,Order">
    <Filter NoTournament="12345" />
  </Request>
</BatchRequest>
```
