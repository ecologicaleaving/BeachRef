# Story 1.2: migrate-core-services-to-vis-types

## Status
Done

## Story
**As a** BeachRef developer,  
**I want** to migrate core parsing and caching services to use VIS-compliant types with proper numeric conversion,  
**so that** the application processes VIS API responses correctly and stores data in the proper format for improved type safety

## Acceptance Criteria

1. **Update `VisResponseParser`** to convert VIS string responses to proper numeric types using the new `VisCompliantMatch` interface
2. **Replace `MatchDurationFormatter`** string parsing with VIS seconds-based `VisDurationParser` that handles numeric duration fields
3. **Update cache services** (`CacheService`, `TournamentStorageService`) to store VIS-compliant data with proper numeric types
4. **Ensure existing API calls** (`GetEventList`, `GetBeachMatchList`) work seamlessly with new types while maintaining backward compatibility
