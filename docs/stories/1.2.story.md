### TTL Configuration Strategy

**Referee TTL Requirements** [Source: CacheImplementationAnalysis.md#Recommended TTL vs Current Implementation]:
- Referee data: 24-hour TTL (matching data stability vs 6-hour tournament TTL)
- Daily caching reduces referee API load by 99% per epic goals
- Extended TTL justified by referee data stability vs dynamic match data

**TTL Implementation Pattern** [Source: CacheImplementationAnalysis.md#Current Cache Configuration]:
```typescript
const config = {
  defaultTTL: {
    tournaments: 24 * 60 * 60 * 1000, // 24 hours
    matchesScheduled: 15 * 60 * 1000, // 15 minutes  
    matchesLive: 30 * 1000, // 30 seconds
    referees: 24 * 60 * 60 * 1000 // 24 hours (NEW)
  }
};
```
