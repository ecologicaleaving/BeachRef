### Repository Layer Implementation Strategy

**Repository Pattern Design:**
```typescript
// New unified repository interface
interface ITournamentRepository {
  // New domain methods
  getByIdAsync(id: string): Promise<TournamentCore | null>;
  getListAsync(filters: TournamentFilters): Promise<TournamentCore[]>;
  
  // Legacy compatibility methods  
  getLegacyByIdAsync(no: string): Promise<Tournament | null>;
  getLegacyListAsync(): Promise<Tournament[]>;
}
```

**Data Flow Architecture:**
1. **Request**: Component → Repository → SmartCacheManager → VisApiClient → VIS API
2. **Response**: VIS API → VisResponseParser → DataTransformationService → SmartCacheManager → Repository → Component
3. **Cache Strategy**: Tier 1 Memory (15min-2h) → Tier 2 Persistent (6h-24h) → API fallback
