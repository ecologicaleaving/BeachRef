### Data Transformation Strategy

**Legacy Interface Compatibility**:
The new repository layer returns modern domain types (TournamentCore, BeachMatchCore) but existing UI components expect legacy interfaces (Tournament, BeachMatch). The DataTransformationService from Story 7.2 provides bi-directional transformation:

```typescript
// Component migration pattern
const TournamentDetail: React.FC<Props> = ({ tournament }) => {
  // Use new repository with transformation
  const { data: tournamentCore, loading, error } = useRepositoryData(
    () => tournamentRepository.getByIdAsync(tournament.id),
    [tournament.id]
  );
  
  // Transform for UI compatibility
  const legacyTournament = useDataTransformation(
    tournamentCore, 
    'coreToLegacy'
  );
  
  // Existing component logic unchanged
  return <ExistingTournamentUI tournament={legacyTournament} />;
};
```

### Hook Design Patterns

**New Hook Architecture**:
Based on existing hook patterns and repository integration requirements:

```typescript
// Unified repository data access
export const useRepositoryData = <T>(
  repositoryMethod: () => Promise<T>,
  dependencies: any[],
  options?: { enableCache?: boolean; transform?: boolean }
): { data: T | null; loading: boolean; error: Error | null; refresh: () => void };

// Data transformation for legacy compatibility
export const useDataTransformation = <T, U>(
  data: T | null,
  transformationType: 'coreToLegacy' | 'legacyToCore'
): U | null;

// Cache-aware data fetching with performance monitoring
export const useCacheAwareData = <T>(
  cacheKey: string,
  fetchMethod: () => Promise<T>,
  options?: { ttl?: number; enablePerformanceTracking?: boolean }
): { data: T | null; loading: boolean; error: Error | null; cacheHit: boolean };
```
